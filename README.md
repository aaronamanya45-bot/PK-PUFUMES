PK Perfumes is an elegant, fully responsive React-based website for a luxury fragrance brand proudly based in Kampala, Uganda. Built with React 18, CSS3, JavaScript, and HTML, the site features three beautifully designed pages: a Home page introducing PK, the founder, with a striking hero image; a Perfumes page showcasing her handpicked signature scent collection with detailed notes and descriptions; and a Contact page displaying store details alongside a live interactive map of Kampala, Uganda powered by Leaflet. To run it locally, clone the repo, run npm install then npm start, and open http://localhost:3000; to deploy, simply build with npm run build and host the build/ folder on Netlify, Vercel, or GitHub Pages.
