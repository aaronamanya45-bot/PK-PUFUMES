PK Perfumes is an elegant, fully responsive single-page website for a luxury fragrance brand proudly based in Kampala, Uganda, built entirely inside one index.html file using HTML, CSS, JavaScript, and React (loaded via CDN) — no build tools or installations required. The site features three seamlessly switching pages: a Home page introducing PK, the founder, with a striking hero image of her; a Perfumes page showcasing her handpicked signature scent collection with descriptions and fragrance notes; and a Contact page displaying store details alongside a live interactive map of Kampala, Uganda powered by Leaflet. To view it, simply download or clone this repository and open index.html in any modern web browser — or upload index.html and the accompanying PK image file together to any static host like GitHub Pages, Netlify, or Vercel for instant deployment.
